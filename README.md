# RoboClass 📚

ربات تلگرام مدیریت تکالیف: دانش‌آموزان تکلیف را (عکس/فایل) می‌فرستند و معلم از طریق پنل، تکالیف را می‌سازد، وضعیت تحویل را می‌بیند و گزارش PDF می‌گیرد.

## امکانات
- ثبت‌نام دانش‌آموز با انتخاب کلاس (کیبورد)
- پنل معلم: کلاس‌ها، دانش‌آموزان، تکالیف، گزارش
- ساخت تکلیف با بازه زمانی (تقویم شمسی) و اعلان خودکار به دانش‌آموزان همان کلاس
- ارسال تکلیف دانش‌آموز برای معلم
- گزارش PDF فارسی (هر دانش‌آموز یک ردیف)
- فایل‌ها روی سرور ذخیره نمی‌شوند؛ فقط `file_id` تلگرام در دیتابیس می‌ماند

## نصب و اجرا
```bash
python -m venv venv
venv\Scripts\activate        # ویندوز  (لینوکس: source venv/bin/activate)
pip install -r requirements.txt
copy .env.example .env       # لینوکس: cp .env.example .env
```
سپس فایل `.env` را باز کن و `BOT_TOKEN` و `TEACHER_IDS` را پر کن، بعد:
```bash
python homework_bot.py
```

## نکات
- تلگرام در ایران فیلتر است؛ ربات را روی سروری خارج از ایران اجرا کن.
- فونت `Vazir-Regular.ttf` برای PDF فارسی کنار فایل ربات قرار دارد (لایسنس OFL، فایل `Vazir-OFL.txt`).
- دیتابیس `homework.db` خودکار ساخته می‌شود؛ از آن پشتیبان بگیر.
- نام کلاس‌ها در لیست `CLASS_NAMES` بالای `homework_bot.py` تنظیم می‌شود.
